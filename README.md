# Anonymous Q&A Forum

Репозиторий содержит исходный PHP-макет и перенос в Android-проект на Java: каталог приложения — [`android/`](android/). Android-версия не использует PHP-сервер, MySQL или Redis; локальный интерфейс и хранилище работают отдельно от сетевого адаптера.

## Запуск Android-приложения

Откройте каталог `android/` в Android Studio либо выполните:

```sh
cd android
./gradlew assembleDebug
```

Нужны JDK 17, Android SDK 35 и Gradle 8.9 (wrapper уже включён). Минимальная версия Android — 8.0 / API 26. В предоставленном `YggChat-0.2.0-arm64.apk` есть только `arm64-v8a`-библиотека, поэтому текущая сборка намеренно ограничена этой ABI. На устройствах без неё Q&A остаётся доступным локально; Ygg-сервис сообщает об отсутствии ядра вместо падения всего приложения.

## Модули

- `MainActivity.java` — компактный интерфейс: «Спросить», лента, приватная страница ответов, настройки и выдвижная боковая панель. Переключатель темы закреплён внизу панели.
- `ForumCore.java` — локальная модель, суточная бесплатная квота, кредиты, дедупликация событий, срок жизни вопросов и очередь исходящих событий. Не зависит от JNI и сохраняет работу в offline-режиме.
- `YggNodeService.java` — foreground-сервис с очередной синхронизацией и gossip-пересылкой между сохранёнными контактами.
- `Strings.java` — автоопределение языка устройства, ручной выбор в «Настройки», темы и подтемы исходного PHP-проекта. Полные общие строки есть на русском и английском; приветствие страницы вопроса также переведено на остальные языки из `functions/lang.php`.
- `net/yggchat/yggchat/Yggchat.java`, `go/Seq.java`, `go/Universe.java` — небольшой JNI-совместимый слой; имена классов и сигнатуры соответствуют Java API из переданного YggChat APK.
- `app/src/main/jniLibs/arm64-v8a/libgojni.so` — извлечённое из переданного APK ядро YggChat 0.2.0 / Yggdrasil v0.5.15. Сообщения форума проходят через его `Node.send`, поэтому задействуются встроенные шифрование, разбиение на осколки, избыточность и vault/TTL-настройки ядра.

## Логика и сеть

- Всем даётся один бесплатный вопрос за UTC-сутки. Каждый дополнительный вопрос стоит 1 кредит. Один ответ от участника на конкретный вопрос приносит этому участнику 1 кредит; повторный ответ на тот же вопрос не начисляет кредит.
- Текст вопроса и тема распространяются по известным YggChat-контактам и пересылаются дальше новыми узлами. Для ответа используется отдельное зашифрованное сообщение непосредственно автору; по общей сети идёт только уведомление без текста ответа. Поэтому автор вопроса может получить ответы от многих анонимных участников, а сами ответы видит только он.
- Вопрос без ответов удаляется после 24 часов. Вопросы с ответами сохраняются локально ограниченное время. Лента фильтруется по темам и подтемам из `config/topics.php`.
- Для подключения откройте «Настройки» → «Добавить узел» и вставьте код контакта участника. Свой код можно передать через «Поделиться кодом узла». Стандартные Yggdrasil peers из APK помогают подключиться к Yggdrasil-overlay, но **не являются списком пользователей форума**: первоначальный контакт/обмен кодами нужен для обнаружения других экземпляров приложения. После этого события распространяются gossip-пересылкой по связям между узлами; центральной базы и API-сервера нет.
- Параметры `ShardSize`, `Redundancy`, `Fanout`, `VaultMax` и `TTLHours` читаются из конфигурации используемого ядра. Кнопка очистки удаляет только локальный shard-vault ядра, не вопросы и ответы в хранилище форума.

## Границы анонимности и доверия

«Анонимно» здесь означает отсутствие аккаунта и публичного имени, но не отсутствие сетевого псевдонима: код узла Yggdrasil нужен для доставки приватного ответа и может связывать сообщения одного узла. Не помещайте личные данные в вопросы.

Кредиты и бесплатный лимит пока локальны для установки приложения. Без аккаунтов, криптографически проверяемой репутации и распределённого консенсуса нельзя надёжно защититься от сброса данных или Sybil-идентичностей; это рабочая прототипная экономика, а не trustless-токен. Аналогично, число просмотров локальное, а поиск участников автоматически не выполняется. Эти ограничения оставлены явными, чтобы не выдавать локальные проверки за гарантии распределённой сети.

Бинарная лицензия/исходники ядра в переданном APK не приложены. Перед публикацией или распространением APK, собранного из этого проекта, необходимо отдельно подтвердить условия распространения нативной библиотеки; заметка об этом лежит в [`android/THIRD_PARTY_NOTICES.md`](android/THIRD_PARTY_NOTICES.md).

## PHP-макет

Старые страницы `public_html/` и `modules/` сохранены как исходный веб-прототип. Их «вопросы», ответы и лента содержали JS-моки, а `settings.php` и `enter.php` были заглушками; они не используются Android-приложением. Модульная схема исходного проекта и добавленная Android-схема описаны в [`Info.txt`](Info.txt).
