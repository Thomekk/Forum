Android-границы: минимальная ОС — Android 5.0 / API 21; UI и локальная Q&A-логика остаются доступны в offline-режиме. Сетевой режим только для 64-битного ARM (`arm64-v8a`). Приложение пытается пакетно проверять NodeInfo видимых узлов текущего Yggdrasil routing tree, но это требует Admin listener в нативном ядре; статическая проверка поставленного `libgojni.so` не подтвердила его наличие, работа на устройстве не проверена. Если Admin API недоступен, приложение сообщает об этом и оставляет публикации локально/в очереди. Узел становится участником только после проверки подписанной Forum-записи, совпадающей с запрошенным ключом/адресом; транспортные узлы сами по себе не считаются участниками. Кэш `lastSeen` имеет TTL шесть часов; при наличии подтверждённых адресатов публичные вопросы и answer-notice передаются direct/gossip до трёх выбранных узлов, приватные ответы не реплицируются. Это не полный глобальный DHT: routing tree может не содержать всех пользователей, а Android background-работа и доставка не гарантированы. Пять URI из официального public-peers списка — только сторонние транспортные bootstrap-точки; начальная связность Yggdrasil всё равно необходима, их доступность не гарантируется. Квота/кредиты пока локальны и не защищены от Sybil-сброса.
